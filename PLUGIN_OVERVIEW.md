# Antigravity

Chat with Antigravity inside BB. Reuse your existing CLI sign-in, choose models reported by the CLI, and see streamed replies and tool approvals in your thread.

Requires a separately installed Antigravity CLI with `agy acp` available on the agent host's PATH and an eligible signed-in account. Account charges or quota limits apply. The Antigravity desktop application alone is insufficient.

The plugin uses the shared BB ACP bridge. It does not install the CLI, collect credentials, or bypass Antigravity's permission checks. Usage accounting, forks, and manual compaction are not supported. Windows is verified; other platforms need validation.
